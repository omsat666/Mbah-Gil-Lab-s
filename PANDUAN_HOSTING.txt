================================================================================
🚀 PANDUAN LENGKAP DEPLOY DIGITAL RESEARCH ASSISTANT KE HOSTING / VPS / CLOUD
================================================================================

Folder ini adalah paket LENGKAP & SIAP PAKAI (Production Ready) yang sudah dikompilasi 
(pre-built) dan dilengkapi Database SQLite, server API, serta Web Frontend UI.

Anda dapat men-deploy aplikasi ini ke berbagai jenis hosting berikut:

--------------------------------------------------------------------------------
OPSI 1: CPANEL HOSTING (MENU "SETUP NODE.JS APP") - PALING BANYAK DIGUNAKAN
--------------------------------------------------------------------------------
Layanan yang mendukung: Niagahoster, DomaiNesia, IDCloudHost, Hostinger cPanel, 
Rumahweb, Dewaweb, dsb yang menyediakan fitur Node.js Selector.

Langkah-langkah:
1. Kompres (ZIP) seluruh isi folder DIGITAL_RESEARCH_ASSISTANT_HOSTING ini.
2. Buka cPanel hosting Anda -> Buka "File Manager".
3. Buat folder baru (misal: `research-app` di luar public_html, atau di home directory).
4. Upload file ZIP tersebut dan Ekstrak (Extract) ke dalam folder `research-app`.
5. Kembali ke halaman utama cPanel -> Buka menu "Setup Node.js App".
6. Klik tombol "Create Application":
   - Node.js version : Pilih versi 20.x atau 22.x (disarankan 22.x jika ada)
   - Application mode: Production
   - Application root: `research-app` (nama folder yang tadi dibuat)
   - Application URL : Masukkan subdomain atau domain Anda (misal: research.domain.com)
   - Application startup file: `server.js` (atau `app.js`)
7. Klik tombol "CREATE".
8. Pada halaman detail aplikasi, klik tombol "Run NPM Install" (otomatis menginstal dependencies).
9. Klik tombol "Restart" atau "Start Application".
10. Buka domain/subdomain Anda di browser. Aplikasi langsung berjalan online!

--------------------------------------------------------------------------------
OPSI 2: CLOUD HOSTING GRATIS / MODERN (RENDER.COM / RAILWAY.APP / FLY.IO)
--------------------------------------------------------------------------------
Sangat direkomendasikan jika ingin hosting online gratis tanpa biaya bulanan:

A. RENDER.COM (Sangat Mudah & Gratis):
1. Buat akun di https://render.com
2. Buat repositori GitHub baru dan upload folder ini ke GitHub Anda.
3. Di dashboard Render, klik "New" -> "Web Service".
4. Hubungkan repositori GitHub Anda.
5. Konfigurasi:
   - Environment  : Node
   - Build Command: (Kosongkan atau ketik `npm install --omit=dev`)
   - Start Command: `node server.js`
6. Klik "Create Web Service". Render akan memberikan URL online gratis HTTPS 
   (misal: `https://digital-research-assistant.onrender.com`).

B. RAILWAY.APP:
1. Buka https://railway.app -> Login dengan GitHub.
2. Klik "New Project" -> "Deploy from GitHub repo" (atau deploy langsung via Railway CLI).
3. Railway otomatis mendeteksi `Dockerfile` atau `package.json` dan menjalankannya.

--------------------------------------------------------------------------------
OPSI 3: VPS LINUX (UBUNTU / DEBIAN) DENGAN PM2 & NGINX
--------------------------------------------------------------------------------
Cocok untuk server mandiri (DigitalOcean, Linode, AWS EC2, IDCloudHost VPS):

1. Upload folder ini ke server (misal ke `/var/www/digital-research-assistant`).
2. Masuk via SSH ke server Anda:
   cd /var/www/digital-research-assistant
3. Install dependencies produksi:
   npm install --omit=dev
4. Jalankan aplikasi di latar belakang dengan PM2:
   npm install -g pm2
   pm2 start ecosystem.config.cjs
   pm2 save
   pm2 startup
5. Setting Nginx sebagai Reverse Proxy (lihat file `nginx.example.conf`):
   sudo cp nginx.example.conf /etc/nginx/sites-available/research-app
   sudo ln -s /etc/nginx/sites-available/research-app /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl reload nginx
6. Pasang SSL gratis dengan Let's Encrypt:
   sudo certbot --nginx -d research.domainanda.com

--------------------------------------------------------------------------------
OPSI 4: DOCKER / DOCKER COMPOSE (1-CLICK CONTAINER DEPLOYMENT)
--------------------------------------------------------------------------------
Jika server Anda sudah memiliki Docker:

1. Buka terminal di dalam folder ini:
2. Jalankan perintah:
   docker compose up -d --build
3. Selesai! Aplikasi langsung aktif di port 3001:
   http://ip-server-anda:3001

--------------------------------------------------------------------------------
OPSI 5: SHARED HOSTING BIASA (TANPA NODE.JS - PUBLIC_HTML)
--------------------------------------------------------------------------------
Jika hosting Anda HANYA berupa Shared Hosting Apache biasa tanpa dukungan Node.js:

1. Buka subfolder: `STATIC_WEB_HOSTING_HTML`.
2. Upload seluruh file yang ada di dalam subfolder tersebut ke `public_html` di cPanel.
3. Aplikasi web front-end akan berjalan langsung di browser menggunakan Web Storage.
   (Untuk fitur server SQLite terpusat dan proxy link ChatGPT, disarankan menggunakan
    Opsi 1, 2, 3, atau 4).

--------------------------------------------------------------------------------
STRUKTUR FOLDER HOSTING:
--------------------------------------------------------------------------------
├── server.js                  <- Entrypoint utama untuk hosting Node.js
├── app.js                     <- Alias entrypoint untuk cPanel Passenger
├── package.json               <- Manifest package produksi Node.js
├── .env                       <- Konfigurasi port & environment
├── database.sqlite            <- File database SQLite siap pakai
├── ecosystem.config.cjs       <- Konfigurasi PM2 Process Manager
├── Procfile                   <- Konfigurasi untuk Render / Railway / Heroku
├── Dockerfile                 <- Docker container manifest
├── docker-compose.yml         <- Docker Compose configuration
├── nginx.example.conf         <- Template konfigurasi Nginx Reverse Proxy
├── dist/                      <- Bundle frontend web yang sudah dikompilasi
├── server/                    <- Backend Express.js, SQLite ORM, ChatGPT Fetcher
├── node_modules/              <- Library runtime produksi siap pakai
└── STATIC_WEB_HOSTING_HTML/   <- Khusus untuk upload ke public_html Apache biasa
